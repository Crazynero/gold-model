## 1. 这个系统能帮你做什么(与不能做什么)

### ✅ 能做的

- **每天给出一个明确的建议**:加仓 / 持有 / 减仓 / 清仓,而不是模棱两可的"可能涨"。
- **告诉你"为什么"**:基于几十个经济因子(利率、美元、波动率等)用机器学习算出的概率。
- **回测验证**:这套策略在过去 5 年表现如何,年化收益、最大回撤、胜率都摆出来。
- **仓位模拟器**:输入你的本金和风险偏好,模拟 1000 条未来走势,告诉你破产概率有多大。
- **监控告警**:命中率下滑、数据异常时自动告警。

### ❌ 不能做的

- **不能保证赚钱**。任何基于历史数据的模型都无法预测黑天鹅事件(战争、疫情、政策突变)。
- **不是全自动交易**。系统给建议,最终买卖决定权和操作权在你。
- **不是投资建议**。本系统是量化研究工具,所有输出仅供参考,不构成任何形式的投资建议。

## 2. 打开网站

### 方式一:本地启动(推荐)

如果你自己运行这套系统:

1. 打开电脑,确认后端程序已经启动(通常开机自动运行,或让帮你装的人启动)。

## 4. 每天必看的 5 分钟流程

每天(交易日晚上 22:30 后数据更新)按这个顺序看:

### 第 1 步:看「总览」(1 分钟)

打开「决策 → 总览」,最上方有一个**晨报决策头**:

```
┌──────────────────────────────────────────────┐
│  预测基准日:2026-08-07    建议操作:【持有】     │
│  综合看多概率:62%  偏多                         │
│  市场状态:震荡    金价:4405.7 美元/盎司          │
└──────────────────────────────────────────────┘
        ↓ 推理链路 ↓
  加权集成概率 → Regime 过滤 → 执行建议
```

**关键看三件事**:
1. **建议操作**(加仓/持有/减仓/清仓)—— 这是最终结论。
2. **综合看多概率** —— 高于 60% 偏多,低于 50% 偏空,50-60% 中性。
3. **市场状态(Regime)** —— 牛市倾向满仓,熊市倾向空仓,震荡轻仓。

### 第 2 步:看「执行方案」(1 分钟)

「决策 → 执行方案」会告诉你**具体怎么操作**:

- 目标仓位百分比(如 60%)
- 资金怎么分配:ETF 层 65% + 期货层 35%
- 下方「执行说明」表给出**逐步操作清单**(第 1 步建仓 ETF、第 2 步……、带金额)

> 💡 可选资金量:页面上方有「10万 / 50万 / 100万 / 500万」按钮,选你的资金规模,金额会自动算好。

### 第 3 步:看「监控墙」(1 分钟)

「决策 → 监控墙」是 9 宫格大屏,快速扫一眼:

- **告警流**(右下角):有没有红色/橙色告警?有就要重视。
- **当前信号**:大数字概率,颜色红绿。
- **关键指标**:夏普、最大回撤、命中率。
- **命中率 vs 基准**:如果命中率明显低于历史基准(黄色/红色),说明模型近期失灵,要谨慎。

### 第 4 步:要不要操作?(1 分钟)

- 如果总览建议和你的**当前持仓一致** → 不用动。
- 如果建议**变化了**(如从"持有"变"减仓")→ 看执行方案的具体步骤。
- 如果**不确定** → 用「仓位模拟器」跑一下风险(见第 5.4 节)。

### 第 5 步:记录(1 分钟)

每周看一次「数据 → 历史趋势」,跟踪模型的命中率、夏普值有没有在退化。

## 5. 决策区——你的主战场

### 5.1 总览(Overview)

**用途**:每天第一眼,看整体结论。

| 区块 | 看什么 | 怎么理解 |
|---|---|---|
| **决策头** | 建议操作 + 综合概率 + Regime + 金价 | 最重要的 4 个数 |
| **当前状态** | 基准日、金价、MA50、MA200 | MA50/MA200 是均线,金价在均线之上=趋势向上 |
| **综合概率** | 大百分比 + 5日/10日/20日/60日条形 | 多周期投票,都>60% 才强势 |
| **过拟合检查** | 全样本夏普 → 样本外夏普 → 衰减% | 衰减越小越可信,>50% 要警惕 |
| **金价图** | 250 天金价 + 均线 | 直观看趋势 |
| **策略演化** | 买入持有 vs V3.0-E 策略净值 | 绿线(策略)在蓝线(持有)之上=策略有效 |
| **ML 模型表现** | 各周期 ACC/AUC/IC | ACC 准确率越高越好(>55% 不错) |

**读懂"建议操作"的生成逻辑**:

```
几十个经济因子 → 机器学习模型 → 算出各周期看多概率
        ↓
   加权集成(综合概率)
        ↓
   Regime 市场状态过滤(牛市放大、熊市抑制)
        ↓
   信号质量熔断(命中率太差时自动降仓)
        ↓
   最终建议:加仓/持有/减仓/清仓 + 仓位%
```

### 5.2 监控墙(Wall)

**用途**:一屏掌握全局,快速发现异常。

9 个格子,重点看:

| 格子 | 内容 | 重点关注 |
|---|---|---|
| **当前信号** | 大概率% + 操作建议 | 颜色:绿=多、红=空 |
| **多周期** | 5D/10D/20D/60D 概率条 | 是否一致(都绿=强信号) |
| **关键指标** | 夏普、回撤、命中率 | 命中率<50% 要警惕 |
| **金价周K** | 蜡烛图 + 均线 | 趋势方向 |
| **策略净值** | 策略 vs 买入持有 | 绿线在蓝线上=跑赢 |
| **过拟合检查** | 衰减% | <30% 健康,>50% 危险 |
| **前 8 特征** | 当前影响金价最大的 8 个因子 | 看哪些因子在驱动 |
| **仓位历史** | 模型/ETF/期货层仓位变化 | 模型近期在加还是减 |
| **告警流** ⭐ | 自动告警列表 | **红色必须处理** |

**告警类型**:
- 🔴 **HIGH**:命中率严重下滑 / 概率大幅漂移 / Regime 切换 —— 慎重,考虑降仓。
- 🟠 **MEDIUM**:命中率轻度下滑 / 因子结构变化 —— 观察。
- ⚪ **LOW**:轻微异常 —— 知道即可。

### 5.3 执行方案(Execution)

**用途**:把"建议"翻译成"具体操作步骤"。

**页面结构**:

1. **执行计划**:目标仓位 + ETF/期货分层 + 杠杆。
2. **执行说明**(表):逐步操作清单——步骤、操作、目标、金额、备注。
3. **信号质量**:命中率 + 基准 + 偏差 + 仓位系数 + 状态(正常/熔断中)。
   - **熔断中**:模型近期表现太差,系统自动把仓位打折(如 ×0.2),这时即便建议"加仓"也要保守。
4. **成本对比**:纯 ETF / 纯期货 / 混合三种方案的成本(佣金、管理费、保证金成本)。
5. **仓位历史图**:模型过去怎么调仓的。
6. **周报**:可生成 PDF 周报存档。

**操作**:
- 点「10万/50万/100万/500万」切换资金量,金额自动重算。
- 点「生成 PDF 周报」下载本周报告。

### 5.4 仓位模拟器(Simulator)⭐ 强烈推荐

**用途**:下单前先模拟——"如果我按这个仓位进场,最坏会亏多少?"

**怎么用**:

1. 填写参数:
   - **本金**:你的实际资金(如 500000)。
   - **杠杆**:1 表示不用杠杆,2 表示 2 倍。
   - **仓位%**:投多少比例(0-100)。
   - **持仓天数**:打算持有多久。
   - **路径数**:默认 1000(越大越准,但更慢)。
   - **波动率来源**:20日 / 60日历史波动率,或自定义。
   - **漂移**:预期日均涨跌(乐观填正、悲观填负,不确定填 0)。
2. 点「运行模拟」。
3. 看结果:

| 指标 | 含义 | 安全线 |
|---|---|---|
| **期望终值** | 1000 次模拟的平均结果 | >0% 即正期望 |
| **中位数** | 一半路径比这好 | 比期望更稳健 |
| **95% VaR** | 最坏 5% 情况亏多少 | 不超过你能承受的 |
| **最大盈利/亏损** | 极端情况 | 亏损不超过本金 |
| **破产概率** ⭐ | 本金亏掉 ≥50% 的概率 | **必须接近 0%** |

> 💡 **决策口诀**:破产概率 >5%,立刻降仓位或降杠杆。

**图表**:
- **路径扇形图**:1000 条可能的未来路径,深色带是 25-75% 区间,浅色带是 5-95% 区间。
- **期末净值分布**:直方图,绿色=赚钱,红色=亏钱。

### 5.5 人工调整(Adjust)

**用途**:模型给建议,但你有自己的判断?在这里手动覆盖。

**三个调节项**:

1. **市场观点**滑块(-5 到 +5):
   - 拖到右边(>2)= 你比模型更看多 → 自动判定"牛市"。
   - 拖到左边(<-2)= 更看空 → "熊市"。
   - 中间 = "震荡"。

2. **仓位调整**滑块(-100% 到 +100%):直接指定目标仓位。

3. **杠杆倍数**(1-5):调节杠杆。

4. **事件叠加**:5 个预设黑天鹅模板(美联储降息、地缘冲突、CPI 超预期、非农、央行购金),点击叠加预估影响。

**应用后**:下方「手动覆盖预览」表显示 模型值 vs 你的调整 vs 差值。点「应用调整」保存到本地浏览器。

> ⚠️ 手动调整只在你这台浏览器生效,不会改变系统对其他人的建议。

## 6. 模型区——验证策略靠不靠谱

> 进阶用户用。普通用户可跳过,信「决策区」即可。

### 6.1 因子分析(Factors)

展示影响金价的 **25 个经济因子**排名(XGBoost 增益)。能看到:哪些因子当前最重要、各因子的数值和方向信号。

### 6.2 回测中心(Backtest Hub)⭐

点击「回测中心」后,顶部出现 **5 个子标签**:

| 子标签 | 内容 | 给谁看 |
|---|---|---|
| **策略回测** | 8 个策略对比表 + 净值曲线 + 回撤 + 雷达图 | 看主策略表现 |
| **策略对比** | 勾选最多 4 个策略做雷达叠加 | 对比选哪个 |
| **版本对比** | V1→V5 演化史 + 雷达 | 看策略进化 |
| **Walk-Forward** | 滚动回测,看稳定性 | 验证不过拟合 |
| **过拟合验证** | 留出集检验 + 诊断 | **看策略是否只是"历史巧合"** |

#### 重点:怎么看「过拟合验证」

- **衰减%** < 30% = 健康(样本外表现接近样本内)。
- **衰减%** > 50% = 危险(策略可能只在过去有效)。
- 看「过拟合诊断」的 3 条红色原因 + 1 条绿色结论,诚实告诉你策略的局限。

#### 重点:策略回测表的关键列

| 列 | 含义 | 好坏 |
|---|---|---|
| **年化收益** | 平均每年赚多少 | 越高越好 |
| **夏普 (SHARPE)** | 风险调整后收益 | **>1.0 合格,>1.5 优秀,>2.0 顶级** |
| **最大回撤 (MAX DD)** | 历史最大亏损幅度 | 越小越好,<20% 算稳健 |
| **胜率** | 盈利天数占比 | >50% 即可 |
| **CALMAR** | 年化收益÷最大回撤 | >1.0 不错 |

### 6.3 信号回测(Signal BT)

**可自定义参数的回测**。你能改:日期范围、策略、止损/止盈、波动率目标、Kelly 仓位、Regime 阈值,还能切换"使用 V5 真实仓位"。改完点「运行」看效果。

### 6.4 事件回测(Event BT)

看策略在 **FOMC 会议日、CPI 公布日、Regime 切换日、概率突变日**这些特殊事件的表现。选事件类型,看历史窗口的收益和超额(Alpha)。

### 6.5 资金归因(Attribution)

用 Brinson 模型分解策略超额收益的来源:
- **配置效应**:靠 Regime 择时赚的。
- **选股效应**:选标的赚的。
- **交互效应**:两者协同。
按牛市/熊市/震荡分别看策略 vs 买入持有。

### 6.6 参数调优(Tuning)

**高级功能**:调整 V5 模型参数(训练窗口、标签周期、特征阈值等),点「运行 V5」重新训练,看结果日志。需要后端支持。

## 7. 数据区——查原始数据

### 7.1 数据管理(Data)

- **原始数据表**:最近 250 天的每日金价、Regime、实际利率、美元指数 DXY、VIX、距 FOMC/CPI 天数、波动率、MA200 偏离%。
- 可按日期搜索、按"全部/近30日/有信号变化"筛选。
- 点「导出 CSV」下载到本地。
- **数据源状态**:yfinance、FRED、Stooq、Alpha Vantage 各抓到多少条。

### 7.2 历史趋势(History)

- 时间范围切换:近 7天 / 30天 / 90天 / 全部。
- 4 张图:**概率时间线、Regime+仓位、ML 指标漂移(ACC/AUC/IC)、最佳夏普时间线**。
- **历史记录表**:每次运行的时间、基准日、金价、Regime、仓位%、概率、夏普、命中率、操作。
- 数据来源:API 模式从 SQLite 读,否则从本地 JSON。

> 💡 看「概率时间线」:如果近期概率从 60% 以上滑到 50% 以下,是转空信号。

| 区块 | 看什么 |
|---|---|
| **数据连接** | 数据源(WS/API/JSON)、最近更新时间、基准日 |

- 命中率下滑 → 看「漂移监控」。

## 9. 核心指标速查表

### 9.1 决策类指标

| 指标 | 含义 | 参考标准 |
|---|---|---|
| **综合看多概率** | 模型认为金价上涨的概率 | >60% 偏多,<50% 偏空 |
| **市场状态 Regime** | 牛市/震荡/熊市 | 牛市满仓,熊市空仓,震荡轻仓 |
| **建议操作** | 加仓/持有/减仓/清仓 | 按字面执行 |
| **目标仓位%** | 建议投入资金比例 | 0-100% |

### 9.2 风险类指标

| 指标 | 含义 | 参考标准 |
|---|---|---|
| **夏普 SHARPE** | 每承担 1 单位风险换来的收益 | >1.0 合格,>1.5 优秀 |
| **最大回撤 MAX DD** | 历史最惨时亏多少 | <20% 稳健 |
| **CALMAR** | 年化收益÷最大回撤 | >1.0 不错 |
| **胜率** | 盈利占比 | >50% 即可 |
| **衰减 Decay%** | 样本外 vs 样本内夏普降幅 | <30% 健康,>50% 危险 |
| **破产概率** | 模拟中本金亏半的概率 | **必须接近 0%** |
| **VaR 95%** | 最坏 5% 情况的亏损 | 不超过你可承受的 |

### 9.3 模型质量指标

| 指标 | 含义 | 参考标准 |
|---|---|---|
| **ACC 准确率** | 方向预测对的比例 | >55% 不错,>60% 优秀 |

## 10. 常见问题 FAQ

### Q1:数据多久更新一次?
每个交易日晚上 22:30 自动更新(美国市场收盘后)。看右上角「UPD」时间确认。

### Q2:建议操作的准确率有多高?
历史回测显示 20 日方向准确率约 55-60%(见各页 ACC 指标)。**这意味着仍有 40-45% 的时候会错**,所以一定要配合仓位管理和止损。

### Q3:模型显示"熔断中"怎么办?
说明模型近期命中率严重下滑。此时即便建议"加仓",系统也会自动把仓位打折(如 ×0.2)。你应该**更加保守**,或等待熔断解除。

### Q4:我应该完全按系统的建议操作吗?
**不建议**。系统是参考工具,最终决定要结合你自己的判断(可用「人工调整」覆盖)。至少做到:
1. 系统建议 + 自己的基本面判断一致时,加大力度。
2. 两者矛盾时,降仓观望。

### Q5:模拟器的"破产概率"是真实的吗?
是基于历史波动率和你的参数用蒙特卡洛模拟的**理论值**,不是未来确定会发生的事。但它能帮你避开明显危险的仓位组合。

### Q6:页面数据不刷新怎么办?
1. 点页面右上角「刷新」按钮。
2. 或在网址后加 `?nocache=1` 强制刷新。
3. 还不行,看「系统区」排查数据源。

### Q7:不同的人看到的建议一样吗?
如果都用同一套系统、同一份数据,**建议是一样的**。「人工调整」只在你本地浏览器生效,不影响别人。

### Q8:"衰减 50%" 是什么意思?
模型在历史训练数据上夏普是 2.0,但在未见过的样本外数据上夏普只有 1.0,降了一半。说明有一定过拟合,实盘表现会打折。

# gold_model 功能点与问题清单

> 分析日期：2026-07-24 ｜ 基于 V4.2 + src 布局改造后的代码实际走查（非文档转述）

## 一、功能点全景

### 1. 数据采集层
| 模块 | 功能 |
|---|---|
| `data_fetcher.py` | 25 个 ticker 采集，五层 fallback（2026-07-25 扩充）：yfinance 主源（含 429 熔断）→ 新浪美股日K（13个）→ 东方财富（curl_cffi 伪装 TLS）→ FRED 替代（10个，含 VIX/GVZ）→ ETF 代理因子（GC=F→GLD×10.75，已修正原 0.1 缩放 bug） |
| `fomc_calendar.py` | FOMC 议息日历，四级 fallback：Fed 官网抓取 → 硬编码历史(2020-2025) → `data/fomc_cache.json` → 模式估算 |
| `cpi_calendar.py` | CPI 发布日历，多级 fallback：第三方聚合站 → 硬编码(2021-2026) → 缓存 → 模式估算（BLS 官网 403 封爬虫） |

### 2. 特征与建模层（`gold_factor_v4.py`，2155 行）
- 35+ 因子：FRED 实际利率(DFII10/5)、名义利率(DGS2/10/30)、收益率曲线利差、联邦基金利率、通胀预期(T10YIE)、FOMC/CPI 事件日历、铜金比、BTC、VIX 期限结构等
- Walk-Forward 验证：训练 500 日 / 测试 60 日 / 步长 30 日，训练集中位数填 NaN
- XGBoost + LightGBM 集成，5/10/20/60 日多周期预测，softmax(IC/0.3) 自适应周期权重

### 3. 策略层
- Regime 识别（MA50/MA200 → 牛/震/熊）+ 非对称仓位（牛市不做空）
- 概率分级仓位（>0.7 满仓 / 0.6-0.7 半仓 / 0.5-0.6 轻仓 / <0.5 空仓）+ 15% Vol 靶向
- 半 Kelly 策略（滚动 20 日命中率驱动）；V1.0/V2.0/V3.0 各变体横向对比

### 4. 输出层
- 8 张策略图表（`outputs/charts_v4/`）+ 8 Sheet Excel 报告（`outputs/reports/`）
- `web/dashboard_data.json` + `web/execution_data.json`（前端数据源，`allow_nan=False` 防 JSON.parse 崩溃）
- 每次运行追加漂移快照到 `data/drift_history.json`（保留 90 条）+ 信号回测基准（滚动命中率/连续错误）

### 5. 监控层
- `signal_alert.py`：6 类触发（Regime 切换、仓位变化≥0.3、概率穿越 0.30/0.35/0.65/0.70）+ 4 类信号回测告警；有告警时退出码=1
- `drift_monitor.py`：7 类漂移检测（准确率/IC/AUC 下降、概率分布偏移、特征排名变化、Regime 分布偏移、夏普下降）

### 6. 执行方案层（`execution_plan/`）
- `signal_analysis.py`：换手率/持仓周期分析，ETF vs 期货 vs 混合三层成本对比 → `analysis.json`
- `generate_charts.py`（6 图）→ `generate_pdf.py`（正文）+ `generate_cover.py`（封面，playwright）

### 7. 展示层（`web/index.html`）
- 纯静态可看：概览、策略对比、因子、原始数据（`/api/*` 失败自动 fallback 读本地 JSON）
- 依赖后端才可用：参数滑杆回测(`/api/backtest`)、一键重跑(`/api/regenerate` SSE)、事件调整/央行购金模拟

## 四、功能对预测黄金走势的价值评估（2026-07-24，基于项目自身回测证据）

> 结论：**项目对"预测"的帮助主要不在预测层，而在风控层。** 工程改造前应先确认预测引擎仍值得投入。

### 4.1 预测层能力比表面弱
- 周期分化：5日 IC=**-0.02**、10日 IC=**-0.04**（负值，不如随机）；20日 IC=+0.06（微弱）；60日 IC=+0.14（最好）
- 60日"准确率80%"有水分：回测期黄金大牛市（Regime 分布 bull 811 / range 279 / bear 167），猜涨天然占优；区分度 **AUC 仅 0.529**，全周期贴近 0.5
- **V1.0 简单线性IC（夏普1.54）≥ V2.0 ML（1.44）**：XGB/LGB 集成未跑赢线性基准，复杂模型增量存疑

### 4.2 真正创造价值的是策略层
- 同一批信号：买入持有夏普 1.25（回撤-25%）→ +Vol靶向夏普 **2.37**（回撤-8.1%）；年化仅 26%→30.6%，**+1.1 夏普全部来自仓位管理**
- "牛市不做空"非对称仓位是关键，但在牛市回测里天然占便宜，样本外有效性未验证
- Kelly 版年化 7.7% 证明过度保守杀死收益；5/10日负IC信号带来月均 20 次调仓，是成本负担

### 4.3 分层结论
| 功能 | 对预测的帮助 | 依据 |
|---|---|---|
| 20/60日信号 + Regime/Vol靶向 | ✅ 核心价值（本质是风控） | 夏普 1.25→2.37，回撤-25%→-8% |
| 监控告警体系 | ✅ 高性价比 | 能快速暴露异常（虽曾发生指标语义误报，已修复） |
| 宏观因子（实际利率/日历/美元） | 🟡 中等 | 重要性排名符合宏观逻辑，但是共识变量非独家 alpha |
| 5/10日短周期预测 | ❌ 负贡献 | IC 为负且放大调仓成本 |
| 执行方案/成本优化 | ❌ 对预测无帮助 | 是"信号可用"前提下的执行层；且 `analysis.json` 为 Regime 修复前（2026-06）数据，调仓统计基于失效模型，需重跑 |
| Dashboard/PDF/Excel | ❌ 交付物 | 研究辅助，不产生 alpha |

如何使用人工调整
① 调整左侧5个市场观点滑块，输入你对基本面的判断（模型看不到的信息）
② 在事件标记中录入近期重大事件，模型会叠加事件冲击
③ 在央行购金补录中手动录入世界黄金协会月度数据
④ 右侧自动计算调整后概率，对比模型原始信号
⑤ 如需修改策略参数，在下方模型参数调整中调滑块
⑥ 每个ⓘ图标可展开详细解释和数据获取指引
市场观点输入 — 你对基本面的判断
大幅宽松←中性→大幅紧缩
这是什么？如何判断？
含义：你对未来3-6个月美联储货币政策方向的预期。降息=宽松(+方向)，加息=紧缩(-方向)。

为什么重要：黄金是不生息资产，美联储利率是持有黄金的机会成本。降息→实际利率↓→金价↑。

如何判断：
  • 看FOMC点阵图：每次议息发布，显示委员对未来利率的预期 → FOMC日历
  • 看CME FedWatch：市场对下次议息的降息/加息概率 → FedWatch工具
  • 看FOMC声明措辞："patient"=偏鸽，"vigilant"=偏鹰
  • 看鲍威尔讲话：国会证词、新闻发布会语气
取值参考：
+5紧急降息50bp+，QE重启
+3常规降息25bp，鸽派指引
+1维持但偏鸽，暗示未来降息
0中性，利率不变
-1维持但偏鹰，暗示未来加息
-3常规加息25bp，鹰派指引
-5激进加息50bp+，QT加速
0%5%10%+
这是什么？如何判断？
含义：你对未来美国CPI同比的预期。黄金是抗通胀工具，通胀↑→金价↑。

为什么重要：意外通胀（超出市场预期）是金价最强驱动之一。模型已含T10YIE（10年盈亏平衡通胀率），但你对未来CPI的判断比市场共识更前瞻。

如何获取数据：
  • BLS官网（美国劳工统计局）：每月中旬发布上月CPI → BLS CPI
  • Cleveland Fed通胀预期：实时通胀预测 → 克利夫兰联储
  • 10年盈亏平衡通胀率：市场隐含预期 → FRED搜索"T10YIE"
取值参考：
2.0%美联储目标，政策正常
3.0%温和通胀，略高于目标
5.0%高通胀，加息压力大
7.0%+恶性通胀，黄金最强环境
和平中等全面冲突
这是什么？如何判断？
含义：你对当前全球地缘政治风险的主观评估。地缘冲突→避险需求↑→金价↑（脉冲式）。

为什么重要：模型无法预测突发事件。地缘冲击是金价短期最大波动来源，但持续性弱（通常2-4周回落）。

如何跟踪：
  • GDELT项目：全球事件实时监控 → GDELT
  • 地缘政治风险指数：Caldara & Iacoviello学术指数 → GPR Index
  • 主要冲突热点：俄乌、中东(以色列/伊朗)、台海、朝鲜半岛
  • VIX脉冲：VIX单日涨>30%通常=地缘冲击
取值参考：
1-2全球和平，无重大冲突
3-4局部紧张但无升级（常态）
5-6冲突升级，制裁/军演
7-8实际军事冲突爆发
9-10全面战争/核威胁
大幅贬值←中性→大幅升值
这是什么？如何判断？
含义：你对未来3个月美元指数(DXY)走势的预期。美元↑→金价↓（负相关，但2022年后弱化）。

为什么重要：黄金以美元计价。模型已含美元指数，但你对未来走势的判断比当前水平更重要。

如何判断：
  • 美元指数DXY：TradingView搜索"USDX"或"DXY"
  • 欧元/美元：DXY中欧元占57%，EUR/USD是核心驱动
  • 美欧利差：2年期国债利差决定汇率趋势 → FRED搜索"T2Y02"
  • 美联储vs ECB政策分化：美联储更鹰→美元强
取值参考：
+5美元危机式贬值(DXY跌5%+)
+3明确贬值趋势(DXY跌2-3%)
0区间震荡
-3明确升值趋势(DXY涨2-3%)
-5美元强势突破(DXY涨5%+)
注意：2022年后央行购金打破传统负相关，美元强+金价强可同时出现。此因子权重已降低。
保守0.5x1.0x激进1.5x
这是什么？如何使用？
含义：你的个人风险偏好系数，直接乘到模型建议仓位上。

不是市场指标，是你自己的参数。

取值参考：
  • 0.5x（保守）：最大回撤容忍<10%，接近退休，资金不能亏
  • 0.75x（稳健）：最大回撤容忍<15%，有稳定收入来源
  • 1.0x（中性）：最大回撤容忍<20%，投资经验3年+
  • 1.25x（积极）：最大回撤容忍<25%，投资经验5年+
  • 1.5x（激进）：最大回撤容忍<30%，高净值+衍生品经验
建议：先用0.5x跑1个月，看模型信号和你心理承受度是否匹配，再逐步调整。

央行购金手动补录 — 模型盲区核心数据
为什么需要手动补录？ 央行购金是2022年后金价最强驱动（年购1000+吨），但月度数据无法自动获取，模型只能用ETF持有量做代理。手动补录可显著提升预测精度。
如何获取央行购金数据？
主要数据源：
  • 世界黄金协会(WGC)季度报告：最权威 → WGC需求趋势
  • IMF国际金融统计：各国央行外汇储备 → IMF IFS
  • 各国央行公告：中国央行(PBOC)、俄罗斯央行(CBR)、印度(RBI)、土耳其(CBRT)
主要买家（2023-2024）：
国家年均购金公布频率
中国(PBOC)~300吨月度
俄罗斯~50吨季度
印度(RBI)~70吨不定期
土耳其~100吨月度
波兰~100吨不定期
判断标准：
  • 月度>100吨 = 强支撑（利多+3%）
  • 月度50-100吨 = 正常（利多+1%）
  • 月度<50吨 = 减速（利空-1%）
  • 月度净卖出 = 利空-3~5%
发布节奏：WGC季度报告通常在每季度结束后2-3周发布。中国央行月度数据在每月第一个周末发布。
